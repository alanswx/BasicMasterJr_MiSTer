Title – WILWESP
System – Basic Master Jr./Basic Master Level II 2
Author – ORANGE JUICE
Publication – Micom Basic (マイコンBASIC) December 1984
Preserved by – TWE
Recommended Emulator – bmjr by Takeda Toshiya [http://takeda-toshiya.my.coocan.jp/common/index.html]

Loading the Game –

Load the .wav file onto the emulator;
Type LOAD WILWSP and press Enter;
After the game loads, type RUN then press Enter.

Game Instructions –

Carry the package on the left all the way to the right while avoiding geting crushed by the MEADYs.
Using the [,] and [.] keys to move, make your way to the left edge of the screen to get the package, then go back to the right edge of the screen to drop it.
If a MEADY manages to crush CORIC, he goes to heaven. If you let CORIC go to heaven 5 times, it's GAME OVER.
Also, if you don't press any keys for too long, KILLER will show up and immmediately send CORIC six-feet under.
To clear a round in this game, carry (round nºx2+1) packages successfully.
